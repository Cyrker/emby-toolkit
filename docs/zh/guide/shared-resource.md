# 共享资源（已退役）

共享资源中心、HDHive/影巢以及 Telegram UserBot 频道监听已经从 ETKvNext 的公开使用路径退役。本页保留为历史入口，旧版实例中的相关配置、表和记录不代表当前中心接口仍可用，也不会在这里继续提供启用或排障步骤。

## 当前资源来源

- 外部资源搜索、订阅协作和转存完成事件统一使用 **MoviePilot**。
- MoviePilot 完成转存后，由 ETKvNext 继续执行本地 115 整理、元数据处理和 Emby 入库。
- Telegram Bot 保留通知和快捷任务入口，不再作为频道监听或 UserBot 资源来源。

## 仍保留的本地能力

### 115 `302` 直链播放

本地 115 账号、整理目录和 STRM 链路仍可使用。ETKvNext 可以为已整理的文件生成 115 `302` 直链，供 Emby 播放反代或其他受支持的播放流程使用。配置和授权方式见 [115 网盘](/zh/guide/p115)。

`302` 直链属于本地 115 播放能力，不依赖共享资源中心、贡献点或远程资源池。

### 虚拟库

虚拟库仍通过独立反向代理端口提供访问，默认端口为 `8097`。规则筛选、TMDb 合集和自定义合集可以作为虚拟媒体库来源；地址、端口、转码开关和用户访问范围在 Emby/ETKvNext 配置中管理。

虚拟库配置属于系统管理边界，普通用户只能按管理员授予的范围访问，不能修改系统级配置。详细说明见 [虚拟库](/zh/guide/custom-collections) 和 [反向代理与虚拟库](/zh/guide/reverse-proxy)。

## 历史数据说明

旧版数据库可能仍保留共享源、求共享或贡献点等历史记录。当前版本不会把这些记录重新变成可用的远程共享流程；如需迁移或清理旧数据，应以独立迁移工具和明确的版本说明为准，不要按旧版页面尝试连接已退役服务。
