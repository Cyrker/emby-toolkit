# 项目概览

ETKvNext 是围绕 Emby 和 115 的媒体处理平台。它以旧版 ETK 的成熟业务逻辑为基线，采用 FastAPI、PostgreSQL、分层应用服务和批量工作流，形成“资源获取 -> 整理 -> 刮削 -> 入库 -> Emby 同步”的闭环。

## 主要能力

- **元数据增强**：TMDb 元数据、中文标题/简介、人物和角色翻译、图片归档。
- **批量工作流**：一部电影或一季剧是一个根任务，分集在任务内部批量处理，不把每一集拆成顶层任务。
- **资源获取**：MoviePilot 是唯一的外部资源与订阅协作来源；本地 115 负责整理、STRM 和播放准备。
- **订阅中心**：追剧、合集补齐、榜单补齐和演员订阅统一管理。
- **虚拟库**：规则筛选实时计算，通过独立反向代理端口提供访问，按管理员配置的范围向用户开放。
- **只读智能排查**：任务中心可按需调用 AI 分析日志和失败原因，不拥有数据库写权限。

## 处理边界

路由层只负责协议和权限校验，应用服务编排任务行为，Repository 负责数据读写，外部服务通过 Integration 适配。用户不需要理解这些分层，但它们保证一个任务的日志、回滚和失败原因不会串到其他任务。
